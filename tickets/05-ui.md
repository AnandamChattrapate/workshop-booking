# Ticket: A cancelled booking still shows "Confirmed"

**Priority:** Medium
**Reported by:** Alice Green, a customer
**Time limit:** 45 minutes

## What happened

> I clicked Cancel on a booking. Nothing changed, so I thought it failed.
> After I refreshed the page, it said Cancelled.

## Steps to reproduce

1. Start the app (database, backend, frontend) as described in README.md. Open http://localhost:3000.
2. Log in as `alice@example.com` with password `Demo123!`.
3. Open **My bookings** (`/bookings`). Keep the status filter on **All**.
4. Click **Cancel** on booking 101.
5. The request succeeds, but the row still says **Confirmed**.
6. Refresh the page. The row now says **Cancelled**.

## Expected behavior

- After a successful cancel, the selected row shows **Cancelled** at once, without a refresh.
- Other bookings do not change.
- Cancelled rows stay visible when the filter is **All**.
- If the cancel request fails, keep the old status and show the existing error message.
- The cancel API already works. Do not change the backend.
